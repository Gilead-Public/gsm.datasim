# Remove the build workspace unless it holds an unrestored backup

Remove the build workspace unless it holds an unrestored backup

## Usage

``` r
.cleanup_workspace(workspace)
```

## Arguments

- workspace:

  Path from
  [`.bundle_workspace()`](https://gilead-public.github.io/gsm.datasim/dev/reference/dot-bundle_workspace.md).

## Value

`NULL`, invisibly.
