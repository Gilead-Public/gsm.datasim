# Prepare the bundle output directory

Prepare the bundle output directory

## Usage

``` r
.prepare_output_dir(output_dir, overwrite)
```

## Arguments

- output_dir:

  Directory to write the bundle into.

- overwrite:

  If `TRUE`, delete a non-empty `output_dir` first; otherwise error when
  it is not empty.

## Value

`output_dir`, invisibly.
